# 星月街角 · Hoshitsuki Street

把一间温暖的便利店，收藏在掌心。雨夜、晴昼、黄昏、2077霓虹夜景、静海镇月面社区与雪乡小仓买在同一个页面里切换，拖动、旋转、缩放，发现门后与街角的小小回应。

在线访问：[星月街角](https://wfcsilence.github.io/hoshitsuki-street/)

## 观看与互动

- GitHub Pages发布自适应完整版：桌面与平板保持正常布局，接近手机尺寸时自动进入横屏观看，确认或等待三秒后展示场景，无需打开系统自动旋转。
- 拖动旋转，滚轮或双指缩放；双击小物件聚焦，再次双击返回原视角。
- 右上角直接切换六种模式，点击雪花进入东北雪乡小镇；切换时保留观看角度。
- 原三个天气保留日语标识与各自的日常景物；赛博场景独立使用英文、未来车辆、无人机、能源电池舱和取餐舱。
- 点击灯牌切换12H／24H；六种场景左下角均可重置视角和互动状态，保留当前天气与私人留言。
- 点击邮筒取出信笺，再点信笺展开；末尾可以留下私人留言。
- 右下角相机先预览当前角度的纪念明信片，确认后下载，声音在首次操作后启用，按M可静音。

雨夜轻点左侧玻璃，能一笔一笔擦出笑脸；晴天有乘风而起的羽毛，黄昏灯光轻轻亮起，未来城市的窗灯会回应街角。墙间百叶窗和分类回收箱也能点击打开。

静海镇以圆形月面环绕中央补给店，居住舱、温室、观景通信站、维修棚与货运舱沿道路相连。气闸、氧气瓶、充电臂与配送机器人可以互动；采样机械臂会让旧样本沉入台下，再把新发现放上升起的空托盘。 每三次采样后，地下升降台托起样本箱，由五轮履带机器人送回货运舱。机器人前置方头与对称双天线，货物存放在后方，行进时双臂放低收拢；向补给店交货时，把货箱放到气闸地面，收臂后关外门，再开内门收货。空地的月尘低低悬浮、缓慢起伏。

雪乡小仓买被远山与红松冷杉林环绕，冻河穿过三座桥，便利店、炕房、熟食店、粮仓、修车棚与林场各有日常。店内有豆浆热粥、新鲜早餐、果蔬、饮料和热盒饭；轻点冰棍柜、狗窝、熊洞、稻草人、烟囱或活动器材，看看它们的回应。冰洞偶尔有锦鲤探头，河上可点击让冰爬犁往返；大爷和大妈沿小路坐车、办事和购物，门会等他们进屋后再合上。公告栏可以读信并留下私人留言。

## 文件与隐私

根目录index.html为包含全部资源的单文件网页，不依赖外部模型、图片或音频。留言只保存在访问者自己的浏览器中，不会上传到GitHub。

独立的手机横屏HTML与小工具ZIP仅在本地单独生成，不上传到这个仓库；小工具包含外置经典脚本与平台相册保存适配。网页版按屏幕尺寸选择布局；小工具包固定横屏展示，两者分别验证。

GitHub Pages使用main分支根目录发布，替换index.html并提交后自动更新。
