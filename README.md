# 星月街角 · Hoshitsuki Street

把一间温暖的便利店，收藏在掌心。雨夜、晴昼、黄昏与2077霓虹夜景在同一个页面里切换，拖动、旋转、缩放，发现门后与街角的小小回应。

在线访问：[星月街角](https://wfcsilence.github.io/hoshitsuki-street/)

## 观看与互动

- 手机确认引导或等待三秒，即可横屏观看，无需开启自动旋转；桌面大屏直接进入。
- 拖动旋转，滚轮或双指缩放；双击小物件聚焦，再次双击返回原视角。
- 右上角切换四种模式，切换时保留角度、位置和大小。
- 原三个天气保留日语标识与各自的日常景物；赛博场景独立使用英文、未来车辆、无人机、能源电池舱和取餐舱。
- 点击灯牌切换12H／24H；赛博模式左下角可重置街角。
- 点击邮筒取出信笺，再点信笺展开；末尾可以留下私人留言。
- 右下角相机保存当前角度的纪念明信片，声音在首次操作后启用，按M可静音。

完整演进见[迭代记录](迭代记录.md)。

## 文件与隐私

根目录index.html为包含全部资源的单文件网页，不依赖外部模型、图片或音频。留言只保存在访问者自己的浏览器中，不会上传到GitHub。

手机小工具另提供离线ZIP，包含外置经典脚本与平台相册保存适配；普通网页和小工具包分别验证。

GitHub Pages使用main分支根目录发布，替换index.html并提交后自动更新。
