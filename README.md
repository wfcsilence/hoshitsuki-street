# 星月通り · Hoshitsuki Street

一座可旋转、缩放与互动的日式便利店微缩街角。包含雨夜、晴昼与雨后黄昏三种天气，以及可发现的小物件、动物和纪念明信片。

在线地址：https://wfcsilence.github.io/hoshitsuki-street/

完整功能演进见 [迭代记录](迭代记录.md)，按主要迭代与二级细节编号整理。

## 观看

- 拖拽旋转，滚轮缩放。
- 点击小物件探索互动，双击聚焦，再次双击返回原视角。
- 右上角切换天气，右下角相机保存明信片。
- 点击邮筒，再点击信封，阅读搭建故事与编辑私人留言。
- 声音在第一次点击页面后启用；按 M 可静音。

## 部署与更新

在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，保存即可。

更新时，用新版网页替换根目录的 `index.html`，提交后 GitHub Pages 会重新发布。

网页为单文件离线 HTML，Three.js、模型、音效和材质均内嵌，不需要安装依赖或执行构建。私人留言保存在访问者自己的浏览器中，不会上传到 GitHub。
